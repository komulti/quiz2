```

```

#### 새 컴포넌트 추가

```
"이미지 뷰어 컴포넌트를 만들어줘:

 - 드래그로 이동
 - 더블 탭으로 줌 토글
 - 모달 바깥 탭하면 닫기
 - WebP 우선, PNG fallback"
```

#### 스토어 추가

```
"퀴즈 세션 상태를 관리하는 Zustand 스토어를 만들어줘:

 - 메서드: startQuiz(pool, mode, settings), submitAnswer(id, selected), nextQuestion()
 - 복수 정답 지원 (answer가 배열일 수 있음)
 - persist 없음 (세션 종료 시 리셋)"
```

## 2. 버그 수정 패턴

### 기본 구조

```
"[어디서] [무엇이] [어떻게] 안 되는지 설명.
 원인을 분석하고 수정해줘."
```

### 실제 사용 예시

#### 증상 + 원인 분석 요청 (권장)

```
"국어 퀴즈를 풀고 학습통계 페이지로 가면 국어 숙련도가 0이야.
 다른 과목은 정상이고 국어만 안 돼.
 원인을 분석하고 수정해줘"
```

#### 비교 기반 디버깅 (강력)

```
"오답노트 탭에서 이미지를 탭하면 브라우저 전체 폭으로 확대되는데,
 퀴즈 페이지에서 같은 이미지를 탭하면 480px 폭으로만 확대돼.
 같은 QuestionImage 컴포넌트를 사용하는데 왜 다른지 원인을 분석하고 수정해줘"
```

> **팁**: "A에서는 되는데 B에서는 안 돼"는 가장 강력한 디버깅 정보.
> Claude가 A와 B의 차이점을 분석해서 정확한 원인을 찾는다.

#### 재현 조건 명시

```
"iPhone Safari에서만 발생하는 문제:
 1. 설정 페이지에서 연결 해제 클릭
 2. 메인으로 돌아옴
 3. 다시 설정 페이지 진입
 4. 이름 입력 팝업이 뜨는데 이전 이름이 비어있음

 Chrome에서는 이전 이름이 자동으로 채워짐.
 원인을 분석하고 수정해줘"
```

## 프롬프트 품질 체크리스트

### 좋은 프롬프트의 조건

- [ ] **구체적**: "버튼 만들어줘" ✗ → "과목 선택 카드 7개를 2열 그리드로" ✓
- [ ] **맥락 포함**: 관련 파일, 스토어, 기존 패턴 언급
- [ ] **완료 기준**: 뭐가 되면 완성인지 명확
- [ ] **하나의 목적**: 한 번에 하나의 기능/수정만
- [ ] **되돌릴 수 있는 단위**: 마음에 안 들면 "원복" 가능한 크기

### 나쁜 프롬프트의 신호

- "전부 다 만들어줘" — 너무 큰 범위
- "알아서 해줘" — 구체적이지 않음
- "예쁘게 해줘" — 주관적, 기준 없음
- 5줄 이상의 요구사항 목록 — 분할 필요
