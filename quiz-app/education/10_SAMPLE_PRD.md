# 고졸 검정고시 퀴즈 챌린지 — PRD

> 이 프로젝트를 처음부터 다시 시작한다면 Day 0에 이 문서를 작성했을 것이다.

---

## 1. 개요

### 한줄 요약
고졸 검정고시 7과목 기출문제를 4지선다 퀴즈로 풀 수 있는 모바일 웹앱.

### 배경
- 고졸 검정고시를 준비하는 수험생들이 기출문제를 효율적으로 반복 학습할 도구가 필요
- 기존 학습 방법(PDF 인쇄, 기출문제집)은 휴대성이 떨어지고 즉각적인 피드백이 없음
- 스마트폰으로 언제 어디서나 짧은 시간에 퀴즈를 풀 수 있는 앱이 있으면 학습 효율이 높아짐

### 목표
- 2018~2025년 기출문제 7과목(한국사/국어/수학/영어/사회/과학/도덕) 약 2,720문제 제공
- 스마트폰에서 직관적으로 퀴즈를 풀고 즉시 피드백 받기
- 오답노트로 틀린 문제만 반복 학습
- 학습 진도와 성과를 시각적으로 확인

---

## 2. 타겟 사용자

### 주 사용자
- 고졸 검정고시를 준비하는 수험생 (10대~30대)
- 스마트폰이 주 학습 도구
- 출퇴근, 쉬는 시간 등 자투리 시간 활용

### 사용 환경
- 모바일 브라우저 (iOS Safari, Android Chrome)
- 불안정한 인터넷 환경 (지하철, 시골 지역)
- 짧은 세션 (5~15분씩)

## 3. 핵심 기능

### P0: 필수 (MVP)

| 기능 | 설명 |
|------|------|
| **과목 선택** | 7과목 중 원하는 과목 선택 |
| **출제 모드** | 랜덤 모드 (전체 문제 셔플) + 년도별 모드 (특정 년도/회차) |
| **퀴즈 풀기** | 4지선다 문제 표시, 선택 시 즉각 정답/오답 피드백 |
| **문제 이미지** | 원본 시험지 이미지 그대로 표시 (텍스트로 변환하지 않음) |
| **결과 화면** | 점수, 소요 시간, 틀린 문제 목록 |
| **오답노트** | 틀린 문제 자동 저장, 과목별 필터, 개별/전체 삭제 |
| **오답 재풀기** | 오답노트의 문제만 모아서 다시 풀기 |
| **데이터 저장** | 기기 내 저장 (새로고침해도 유지) |

### P1: 중요 (MVP 직후)

| 기능 | 설명 |
|------|------|
| **닉네임 로그인** | 닉네임 입력으로 간편 식별 (이메일/비번 없음) |
| **클라우드 동기화** | 다른 기기에서도 내 기록 접근 |
| **리더보드** | 전체 사용자 상위 10명 표시 |
| **해설** | 문제별 해설 표시 (정답 선택지 설명 + 오답 분석) |
| **로딩/에러 화면** | 앱 시작 로딩 + 인터넷 불량 시 안내 |

### P2: 있으면 좋음 (나중에)

| 기능 | 설명 |
|------|------|
| **학습 통계** | 총 풀이 수, 평균 정답률, 연속 학습일, 과목별 숙련도 |
| **레이더 차트** | 과목별 정답률 시각화 |
| **뱃지/업적** | 학습 동기부여 (첫 만점, 연속 3일, 100문제 등) |
| **레벨 시스템** | 총 정답 수 기반 6단계 레벨 |
| **PWA** | 홈 화면 설치, 오프라인 접속 |
| **효과음** | 정답/오답 시 사운드 피드백 |
| **애니메이션** | 문제 전환 슬라이드, 정답 축하 효과, 오답 흔들림 |
| **키보드 단축키** | 1-4로 답안 선택, Enter로 다음 문제 |
| **이미지 핀치줌** | 문제 이미지 탭하여 확대, 핀치로 줌 |

## 4. 사용자 흐름

### 4-1. 첫 방문 → 퀴즈 풀기

```
1. 앱 접속 (로딩 화면 표시)
2. 메인 화면: 7과목 카드 표시
3. 과목 카드 탭 (예: 한국사)
4. 설정 화면:
   a. 이름 입력 팝업 (최초 1회)
   b. 출제 모드 선택 (랜덤/년도별/오답)
   c. 문제 수 선택 (10/25/50/100/200)
   d. '시작' 버튼 탭
5. 퀴즈 화면:
   a. 문제 이미지 표시
   b. 4개 선택지 중 하나 탭
   c. 정답/오답 피드백 (색상 + 효과음 + 애니메이션)
   d. '다음 문제' 탭
   e. (반복)
6. 결과 화면:
   a. 점수 + 소요 시간
   b. 등급 (A+/A/B/C/F)
   c. 오답 목록 (펼쳐서 해설 확인)
   d. '다시 풀기' / '오답만 풀기' / '메인으로' 선택
```

### 4-2. 오답 복습

```
1. 하단 내비게이션 → '오답노트' 탭
2. 과목별 탭으로 필터링
3. 틀린 문제 목록 확인
4. 개별 문제 펼쳐서 이미지 + 해설 확인
5. '오답 N개 풀기' 버튼 → 퀴즈 시작
```

### 4-3. 학습 현황 확인

```
1. 하단 내비게이션 → '학습통계' 탭
2. 종합 지표: 풀이 수, 정답률, 문제 수
3. 레벨 + 경험치 바
4. 획득 뱃지 확인
5. 과목별 숙련도 + 레이더 차트
6. 시간대별 학습 패턴
```

## 5. 기술 요구사항

### 플랫폼
- **모바일 웹** (반응형, max-width: 480px)
- iOS Safari 15+, Android Chrome 90+
- 데스크톱 브라우저도 지원 (중앙 정렬 레이아웃)

### 성능
- 앱 초기 로딩: 3초 이내 (캐시 후 1초 이내)
- 문제 전환: 즉각 (0.25초 애니메이션)
- 이미지 로딩: lazy load + WebP 최적화

### 호스팅
- 정적 호스팅 (GitHub Pages)
- CDN 불필요 (이미지 포함 ~50MB)
- 커스텀 도메인 불필요

### 오프라인
- 서비스워커로 전체 앱 + 이미지 캐시
- 인터넷 없이 퀴즈 풀기 가능
- 온라인 복귀 시 클라우드 자동 동기화

## 6. 데이터

### 원본 데이터
- 고졸 검정고시 기출문제 PDF 16개 (2018~2025, 각 2회차)
- 정답표 PDF 1개
- 7과목 × 8년 × 2회차 × 20~25문제 = 약 2,720문제

### 데이터 가공
- Python 스크립트로 PDF → JSON 변환
- 문제 이미지: PDF에서 캡처 → PNG → WebP 변환
- 해설: 수동 입력 (선택적)

### 데이터 형식 (JSON)
```json
{
  "id": "kh_2024_1_15",
  "year": 2024,
  "session": 1,
  "number": 15,
  "text": "다음 중...",
  "image": "images/kh_2024_1_15.png",
  "passageImage": "images/pass_22_23_kh_2024_1.png",
  "options": [
    { "number": 1, "text": "선택지 1" },
    { "number": 2, "text": "선택지 2" },
    { "number": 3, "text": "선택지 3" },
    { "number": 4, "text": "선택지 4" }
  ],
  "answer": 3,
  "explanation": "정답은 ③..."
}
```

### 클라우드 데이터 (Firebase Firestore)
```
/users/{nickname}
  ├── leaderboard: [최고 기록 3개]
  ├── wrongNotes: [오답 최대 400개]
  ├── history: [풀이 기록 최대 50개]
  └── updatedAt: timestamp

/globalLeaderboard/{entryId}
  └── 전체 상위 10명
```
